# OpenCC

The character pairs in `variants.js` are derived from OpenCC 1.1.9
(`STCharacters.txt` and `TSCharacters.txt`). The search fallback keeps the first
single-character variant of each entry. The dictionaries have been converted
to JavaScript and unchanged pairs have been omitted.
